# franciscocaldas.me

Personal portfolio website, live at [franciscocaldas.me](https://franciscocaldas.me).

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
